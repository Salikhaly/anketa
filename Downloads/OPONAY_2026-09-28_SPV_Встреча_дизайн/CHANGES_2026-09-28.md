# OPONAY — этап правки 2026-09-28

Сделано:

1. Главная (`index.html`)
   - Убрана встроенная простыня/iframe.
   - Звонок открывается напрямую в `1.0.html`.
   - Общий маршрут: Звонок → СПИН → СПВ → Встреча → Возражения → Продажа.
   - Единый синий дизайн.

2. Холодный звонок (`1.0.html`)
   - Сохранён исходный рабочий диалог.
   - Убран визуальный переход/панель СПИН из самого звонка.
   - Убран пункт перехода в СПИН из правого окна.
   - Добавлена только кнопка `← Академия`.

3. СПИН (`spin.html`)
   - Отдельная рабочая страница.
   - 18 цепочек С → П → И → Н.
   - Карта болей.
   - Поиск.
   - Ясное объяснение, когда переходить в СПВ.

4. СПВ (`spv.html`)
   - Полностью отдельная страница без `spv-source.html`.
   - 24 карточки из рабочего материала.
   - Формат каждой карточки:
     `Проблема → Свойство → Преимущество → Выгода → Ключевая ценность → Как сказать клиенту → Понимание этапа`.
   - Фильтр по категориям и поиск.
   - Визуальный формат приближен к загруженному образцу с раскрываемыми карточками.

5. Встреча (`meeting.html`)
   - Полностью отдельный маршрут по этапам.
   - Подготовка, Приветствие + ТМР, СПИН, Презентация, Цена/продажа, Возражение, Закрытие.
   - У каждого этапа есть `Цель` и `Понимание`.
   - Чеклист подготовки с прогрессом.
   - Поиск по цепочкам СПИН.
   - Возражения остаются отдельным модулем.

6. Общий стиль (`academy.css`)
   - Белый фон/карточки, OPONAY blue, мягкие границы, одинаковая типографика и адаптивность.
