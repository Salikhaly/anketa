# OPONAY — полный курс менеджера

## Что внутри
- `index.html` — единая оболочка с сохранёнными рабочими модулями.
- `1.0.html` — исходный интерактивный модуль звонка, не заменён.
- `script.js` — рабочий скрипт/ветки из исходного проекта.
- `spv-source.html` — исходный расширенный материал по СПВ/встрече.
- `course.html` — новый полный учебный слой: звонок → СПИН → боль → СПВ → встреча → возражения → практика → экзамен.

## Логика курса
Ответ клиента → следующий вопрос → проблема → последствия → желаемый результат → подтверждение → СПВ → ключевая ценность → цена/следующий шаг.

## Важное
Старый звонок и его отдельные блоки «Возражения» / «Вопросы и Инфа» сохранены. Новый `course.html` — обучение поверх существующего материала, а не замена рабочего скрипта.
