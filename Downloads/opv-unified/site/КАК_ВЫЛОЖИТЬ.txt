КАК ВЫЛОЖИТЬ ЛЕНДИНГ В ИНТЕРНЕТ
================================

В этой папке лежит index.html — это и есть продающая страница.
Файл один, самодостаточный: шрифты и картинки внутри него,
интернет-зависимостей нет.

ПЕРЕД ВЫКЛАДКОЙ
---------------
Откройте index.html, найдите в самом конце строку:

    var SERVICE_URL = '';

Впишите между кавычек адрес своего сервиса — тот, что оканчивается
на /exec. Тогда в шапке лендинга появится кнопка «Войти» для тех,
у кого доступ уже куплен. Оставите пустым — кнопки просто не будет.


СПОСОБ 1 — VERCEL (рекомендую, ссылка короткая)
------------------------------------------------
В терминале, находясь в ЭТОЙ папке:

    cd C:\Users\Шолпан\Downloads\opv-unified\site
    vercel --prod

При первом запуске Vercel спросит:
  - Set up and deploy? — Y
  - Which scope? — ваш аккаунт (Enter)
  - Link to existing project? — N  (это НОВЫЙ проект, не путать с парсером)
  - Project name? — например: opv-landing
  - In which directory is your code? — ./  (Enter)
  - Модифицировать настройки? — N

Получите ссылку вида https://opv-landing.vercel.app — её и отправляйте
клиентам. Поменять адрес можно потом: vercel.com → проект → Settings → Domains.

Чтобы обновить лендинг позже — правите index.html и снова:
    vercel --prod


СПОСОБ 2 — GITHUB PAGES (бесплатно, но ссылка длиннее)
-------------------------------------------------------
Репозиторий публичный, файл уже в нём. Ничего заливать не нужно:

  1. github.com/Salikhaly/anketa → Settings → Pages
  2. Source: Deploy from a branch
  3. Branch: main, папка: / (root) → Save
  4. Подождать 1–2 минуты

Ссылка получится длинная:
  salikhaly.github.io/anketa/Downloads/opv-unified/site/

ВАЖНО: этот способ работает только после git push — иначе на GitHub
останется старая версия страницы.
