СЕРВЕРНЫЙ ПАРСЕР ПКБ/ГКБ — деплой на VERCEL
=============================================

Что это: Python-сервис. Браузер шлёт ему PDF кредитного отчёта, он
распознаёт (тот же код, что в десктопе) и возвращает превью + Excel.
Ничего не хранит.

Файлы:
  api/index.py     — точка входа для Vercel (подтягивает service.py)
  service.py       — веб-эндпоинты (/parse, /health)
  parser_core.py   — обёртка над main.py (PDF → превью + Excel)
  main.py          — сам парсер (ПКБ + ГКБ)
  license.py       — проверка подписки через твой Apps Script
  assets/template.xlsx — шаблон анкеты
  vercel.json      — настройка Vercel (маршруты + таймаут)
  requirements.txt — зависимости (без OCR — см. ниже)

--------------------------------------------------------------
ДЕПЛОЙ (5 минут):

1. Установи Node.js (nodejs.org), потом Vercel CLI:
   npm i -g vercel

2. Зайди в эту папку (server/) в терминале и выполни:
   vercel
   — первый раз попросит войти (откроется браузер) и подтвердить проект.
   Согласись со всеми вопросами по умолчанию (Enter).

3. Задай переменную окружения (URL твоего Apps Script):
   vercel env add APPS_SCRIPT_URL
   — вставь свой https://script.google.com/macros/s/…/exec, выбери "Production".

4. Финальный деплой:
   vercel --prod
   В конце покажет URL вида:  https://pkb-parser-xxxx.vercel.app
   Скопируй его.

5. В Index.html найди:   var PARSER_API = '';
   Впиши URL:            var PARSER_API = 'https://pkb-parser-xxxx.vercel.app';
   Перезалей Index в Apps Script.

Готово — во вкладке «Парсер» можно грузить PDF прямо в браузере.

--------------------------------------------------------------
ОГРАНИЧЕНИЯ VERCEL (честно):
  • Работает для ТЕКСТОВЫХ PDF (отчёты с 1cb.kz / id.mkb.kz — такие).
  • СКАНЫ (фото/картинки внутри PDF) НЕ распознаются — на Vercel нет OCR
    (tesseract). Для сканов используй десктоп-версию.
  • Размер файла — до ~4.5 МБ на бесплатном тарифе. Обычные отчёты меньше.
  • Таймаут 60 сек (задан в vercel.json) — отчётам хватает с запасом.

Если нужны сканы/большие файлы — альтернатива Google Cloud Run
(есть Dockerfile с tesseract; шаги — по запросу).

ПРИВАТНОСТЬ: файл обрабатывается во временной папке и сразу удаляется,
ничего не логируется/не хранится. Соединение — HTTPS.
СТОИМОСТЬ: бесплатный тариф Vercel Hobby покрывает твои объёмы (~$0).
