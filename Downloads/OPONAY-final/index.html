🎓 Учение менеджера

Не просто читать скрипт. Сначала понять логику → затем выучить формулировки → затем пройти тренировку. Старый рабочий звонок при этом остаётся отдельным модулем.

1. Главная логика

Не продаём всё подряд. Сначала понимаем ситуацию клиента, находим реальную боль, подтверждаем её, затем показываем только нужное решение. В телефонном звонке главная цель — договориться о встрече.

2. Боль клиента

Ищем, где собственник теряет деньги, время, контроль, продажи или товар. После ответа клиента не перескакиваем сразу к функции: уточняем проблему и последствия.

3. СПВ

СвойствоЧто умеет программа.
ПреимуществоЧто меняется в работе клиента.
ВыгодаЧто клиент получает в деньгах, времени, контроле или продажах.

4. Ключевая ценность

После нескольких СПВ собираем всё в один результат: меньше потерь + больше контроля + экономия времени + возможность роста. Только после этого переход к комплекту и цене.

5. Встреча

Приветствие → короткий план → 2–5 вопросов → боль и последствия → подтверждение → только нужные функции через СПВ → ключевая ценность → цена/сотрудничество. Возражения здесь не смешиваем: они отдельным блоком.

6. Контроль знаний

Что делаем после того, как клиент назвал боль?
Где находятся возражения?

🧩 СПВ — отдельный модуль

Здесь менеджер учится не перечислять функции, а связывать каждую функцию с конкретной болью и измеримой выгодой.

🤝 Встреча

Возражения не смешиваем со встречей. Встреча ведётся по диагностической логике.

Маршрут встречи

1. Приветствие

Знакомство → ТМР → озвучить план встречи.

2. Диагностика

2–5 вопросов по бизнесу без допроса.

3. Боль

Найти конкретную проблему и последствия.

4. СПВ

Показываем только функции, которые закрывают найденную боль.

5. Ценность

Собираем результат: меньше потерь, больше контроля, экономия времени, рост.

6. Цена

Переходим к цене после того, как клиент понял ценность.

Правило менеджера

Если клиент сказал: «У меня проблема с кассой» — не отвечаем списком из 20 функций.
